# 🎮 tinyLM-10M-ru

Лёгковесная языковая модель (~10 млн параметров) для генерации диалогов на русском языке. Предназначена как база для дообучения в геймдев‑сегменте: создание диалоговых моделей внутри игр без высокой нагрузки на систему.

## Назначение 🎯

Модель сфокусирована исключительно на:
- связной речи и естественном построении реплик;
- стиле общения и типичных паттернах диалога;
- разговорной лексике и сленге;
- поддержании контекста в коротких диалогах.

Модель **не предназначена** для программирования, проектирования, генерации изображений, сложных рассуждений и мультимодальных задач. Только текст, только диалог, только русский язык.

## Ключевые особенности ✨

- **Малый размер** — ~10 млн параметров: работает на устройствах с ограниченными ресурсами, легко встраивается в игровые движки.
- **Узкая специализация** — обучение сконцентрировано на языковом поведении и структуре диалога, без «размытия» на несвязанные задачи.
- **Гибкость под дообучение** — оптимизирована для быстрой адаптации под конкретную игровую вселенную, персонажей и стилистику.
- **Поддержка системных промптов** — позволяет управлять стилем и поведением через системный промпт.

## Сценарии использования 🕹️

- Генерация реплик NPC в играх (бытовые диалоги, квесты, реакции на действия игрока).
- Создание базы для дообучения под конкретного персонажа или сеттинг.
- Прототипирование диалоговых систем с минимальными требованиями к железу.
- Тестирование механик диалогов и ветвлений в игровых сценариях.

## Требования и ограничения ⚠️

- Язык: только русский.
- Входные данные: текстовые диалоги, системные промпты.
- Не рассчитана на многошаговые логические рассуждения, код, формулы, генерацию медиа.
